# أمثلة عملية على الاستعلامات في Entity Framework Core

## نبذة عن المشروع

يحتوي هذا المستودع على مجموعة من الأمثلة العملية والبسيطة التي توضّح كيفية كتابة وتنفيذ الاستعلامات (Queries) باستخدام Entity Framework Core (EF Core)، وهو إطار عمل من نوع ORM (Object-Relational Mapping) يُستخدم في تطبيقات .NET للتعامل مع قواعد البيانات.

الهدف من هذا المشروع هو تقديم مرجع عملي وسهل الفهم للمطورين الذين يرغبون في تعلّم أو مراجعة أساليب كتابة الاستعلامات بكفاءة باستخدام لغة LINQ ضمن بيئة EF Core.

## ملاحظة
 
سيتم إضافة حلول المسائل (Problems) بشكل تدريجي ومستمر إلى هذا المستودع، حيث لا يحتوي حاليًا على جميع الأمثلة، وسيتم تحديثه أولًا بأول.

## المحتويات

يغطي هذا المستودع المواضيع التالية:

- استعلامات LINQ الأساسية (Select، Where، OrderBy...)
- الفلترة والترتيب المتقدم للبيانات
- استعلامات الربط بين الجداول (Joins)
- الإسقاطات (Projections) وتحويل النتائج
- التحميل الشغوف والكسول (Eager Loading / Lazy Loading)
- استخدام `AsNoTracking` لتحسين الأداء في العمليات القرائية

## هيكلية المشروع

```
Simple-Practices-In-EF-Core/
│
├── Models/              # النماذج (الكيانات) الخاصة بقاعدة البيانات
├── Data/                # إعدادات DbContext والاتصال بقاعدة البيانات
├── Queries/             # أمثلة الاستعلامات المصنّفة حسب النوع
├── Program.cs           # نقطة انطلاق التطبيق
└── README.md            # هذا الملف
```
